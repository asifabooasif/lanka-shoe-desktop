# Lanka Shoe Enterprise — LAN Edition

Desktop accounting suite for shoe retailers. Runs entirely on your
local network. No internet required.

## Download

Get the installer from [Releases](../../releases).

## Install

1. Download `Lanka Shoe Enterprise Setup 12.0.0.exe`
2. Run the installer
3. On first launch, choose **Server PC** or **Client PC**

## Server PC Setup

1. Install the app
2. First launch → select **Server PC**
3. Keep default data folder (`C:\LankaShoe`)
4. Optional: set a PIN for client access
5. Note the URL shown (e.g. `http://192.168.1.100:3000`)
6. Allow through Windows Firewall when prompted

## Client PC Setup

1. Install the app
2. First launch → select **Client PC**
3. Enter the server IP
4. Click **Test Connection** → then **Connect**

## Data & Backup

- Data file: `C:\LankaShoe\data.json` (server PC only)
- Auto-backups: hourly, kept 48 hours
- Manual backup: **Server menu → 💾 Backup Now**

## Requirements

- Windows 10 or 11 (64-bit)
- All PCs on same WiFi or LAN cable
- No internet required
